# Versioning And Upgrades

`VERSION` is the current source version of Agent-Repo-Harness.

`CHANGELOG.md` records user-visible changes between released versions.

Releases in the `v0.x` series may still change templates and workflow
conventions as the harness matures. Installed target repositories should
review relevant `CHANGELOG.md` entries before copying updated templates or
other harness files into their repository.

Backward compatibility is best-effort before v1.0.
